## 🚀 Cara Menjalankan

### 1. Java (Semester 1 / PBO)

Masuk ke folder tugas terkait, lalu kompilasi dan jalankan:

```bash
javac NamaFile.java
java NamaFile
```

### 2. Python / Flask (Semester 3 PWP)

Masuk ke direktori pertemuan terkait (misalnya `Semester 3/PWP/Pert 4`):

```bash
python -m venv .venv
source .venv/Scripts/activate  # Windows Git Bash
pip install -r requirements.txt
flask run
```

> [!NOTE]
> Pastikan service **MySQL** sudah aktif dan file `.env` sudah disesuaikan sebelum menjalankan aplikasi Flask.
